# Посадочные страницы и товарный фид магазина отделочных материалов

Две продающие страницы под контекстную рекламу — плитка с керамогранитом и напольные
покрытия — с квизом-калькулятором, приёмом заявок и выгрузкой товарного фида для
Яндекс.Директа. Статика, никакой CMS: контент приезжает из выгрузки каталога магазина.

## Состав

| Каталог | Что это |
|---|---|
| `site/` | Astro 7, статическая сборка. Отдаётся nginx, он же проксирует `/api/` |
| `api/` | Приём заявок: Bun + SQLite, без единой зависимости |
| `pipeline/` | Python: выгрузка каталога (CSV) → `catalog.json` → YML-фиды и данные для витрины |
| `docker-compose.yml` | Локальный запуск |
| `docker-compose.prod.yml` | Стенд на сервере: те же образы, лимиты памяти, порт наружу |

Внутренние рабочие документы проекта и материалы заказчика в репозиторий не входят —
см. `.gitignore`, там расписано, что и почему остаётся на рабочей машине.

## Локальный запуск

На хосте нужен только Docker:

```bash
docker compose up -d --build
# сайт      → http://localhost:8104/poly
# заявки    → http://localhost:8105/health
```

Порты 8104/8105 выбраны как свободные, менять — сверившись с `docker ps`.

## Пайплайн каталога

Работает на стандартной библиотеке Python 3.13, ставить нечего:

```bash
python3 pipeline/build_catalog.py    # выгрузка CSV → data/catalog.json
python3 pipeline/build_feed.py       # → data/feeds/*.yml для Яндекс.Директа
python3 pipeline/build_showcase.py   # → витрина и данные квиза в site/
python3 pipeline/fetch_images.py     # фото товаров → WebP в site/public/showcase/
```

Сама выгрузка каталога в git не ходит: в ней есть закупочные цены магазина.
Подробности — `pipeline/README.md`.

## Выкатка

Push в `master` → GitHub Actions заходит на сервер по SSH, обновляет код, пересобирает
и поднимает контейнеры, затем проверяет, что страница отдаётся, заявки проходят
через nginx до API, а несуществующий адрес отвечает 404.

Адрес сервера, пользователь и путь заданы секретами репозитория
(`VPS_HOST`, `VPS_USER`, `VPS_PATH`, `VPS_SSH_KEY`) — в коде их нет.
Параметры стенда — в `.env` на сервере, шаблон рядом: `.env.example`.

**Грабля:** `PUBLIC_SITE_URL` и `PUBLIC_INDEXABLE` печатаются в статику на этапе сборки
(canonical, OG, `robots.txt`). Меняются только пересборкой образа, рестарта недостаточно.
Пока стенд закрыт от индексации: `PUBLIC_INDEXABLE=0`.
